__SUBTITLE__

A system is on the frontier (yellow ring, dashed line) when no other system is at least as accurate and cheaper, or at least as accurate and faster. Lot outline accuracy is mean overlap (IoU) with the hand trace over every try, with an unusable polygon counted as zero. Stall accuracy is 1 minus the mean count error against the hand count. Stripe lines have no hand-traced answer yet, so a model judge scores them; that section names its judge and calibration.

Each lot was tried 2 or 3 times per system and every try counts. Cost is the API list price for the tokens each try used (prices for some models come from secondary sources). Latency is wall-clock per try.
